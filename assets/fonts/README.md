# Fonts

Montserrat, SIL Open Font License 1.1 (see `OFL.txt`).
Source: https://github.com/google/fonts/tree/main/ofl/montserrat

- `Montserrat[wght].ttf`: variable font as published (for HTML/CSS templates).
- `Montserrat-Bold.ttf`, `Montserrat-ExtraBold.ttf`: static instances for libass/ASS, created with
  `fonttools varLib.instancer "Montserrat[wght].ttf" wght=800 --update-name-table`.
  ASS family name of the ExtraBold instance: `Montserrat ExtraBold`.
